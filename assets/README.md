# RohrPlan-App-Symbol

Vom Anwender am 06.10.2026 freigegeben: gebogenes metallisches Rohr als R auf einer graublauen Kachel. Bildgenerierung mit dem integrierten image_gen-Werkzeug, transparenter Hintergrund.

- `rohrplan-logo-source.png`: unveränderte generierte Bildquelle.
- `rohrplan.ico`: Windows-Symbol mit 16, 24, 32, 48, 64, 128 und 256 Pixeln.
- `rohrplan.png`: 512-Pixel-PNG für die App.
- `favicon.png`: 32-Pixel-PNG für Browser-Tabs.
- `create-icons.py`: Formatkonvertierung mit Pillow, ohne Retusche.

## Generierungsprompt

Use case: logo-brand. Create one finished Windows desktop application icon for RohrPlan, a German application for isometric tube design and bending planning. Square icon, centered, professionally designed, readable at 32x32 pixels. A bold bent metal tube with rounded 90-degree elbows arranged as a simple R-inspired geometric mark, shown in a restrained isometric view, with a clearly visible open circular tube end. Light steel and sky blue tube, dark slate blue rounded square tile matching a modern gray-blue CAD interface. Large silhouette, generous balanced margins, minimal detail, crisp polished edges, subtle metal shading, flat front-facing square tile. Transparent outside the rounded tile, genuine alpha channel. No words, no small text, no watermark, no desktop mockup, no extra icons, no detailed background or grid. Output the actual icon artwork only.
